# Architecture decision records

This project's architecture choices and deviations, one file each: `ADR-<n>-<slug>.md`, from `.satt/templates/adr.md`. The reference architecture in `.satt/reference/` holds wherever no accepted ADR says otherwise. Only the human accepts an ADR, and only an accepted ADR's `Exception:` lines excuse a check failure. Written through `.satt/procedures/architect.md`.
